# Публикация

Сайт статический: серверный код, база данных и секреты не требуются.

Загрузите **содержимое папки `dist`** в корень сайта на хостинге с HTTPS.
`production.zip` содержит те же файлы, включая оптимизированные изображения.
Исходные PNG, презентация, инструменты сборки и `node_modules` в публикацию не входят.

## Обновление

После правок HTML, CSS или JS:

```powershell
npm.cmd run check
npm.cmd run build
Compress-Archive -Path dist/* -DestinationPath production.zip -Force
```

Если обновляете исходные изображения, сначала выполните `npm.cmd run optimize`.
Этот шаг создаёт WebP в `assets/optimized`; оригиналы сохраняются.
Для установки инструмента оптимизации нужен доступ к npm: `npm.cmd install`.

Сборка добавляет версию CSS и JS для обновления браузерного кеша.
Файл `_headers` поддерживается, например, статическими хостингами Cloudflare Pages
и Netlify; на другом хостинге заголовки кеширования задаются в его настройках.

После выбора домена можно добавить canonical URL, og:url и sitemap с реальным адресом.
Шрифт Montserrat загружается с Google Fonts; при недоступности используется системный шрифт.
